Sinus- und Cosinusfunktionen interaktiv

Amplitude, Periodenlänge und Verschiebungen direkt vergleichen.

Funktionsgraphen

fsin(x) = a · sin(b · (x − c)) + dfcos(x) = a · cos(b · (x − c)) + d

Dargestellt ist der Bereich −2π ≤ x ≤ 2π; die y-Achse passt sich bei größeren Auslenkungen an.

Einstellungen

Bedeutung der Parameter

a
Amplitude: |a|. Bei a < 0 erfolgt eine Spiegelung an der Mittellinie.
b
Horizontale Stauchung oder Streckung. Die Periodenlänge ist T = 2π/b.
c
Verschiebung in x-Richtung: c > 0 verschiebt die Kurve nach rechts.
d
Verschiebung in y-Richtung: Die Mittellinie liegt bei y = d.
