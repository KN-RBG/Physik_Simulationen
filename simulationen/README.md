# Browser-Simulationen

Für jede freigegebene Browser-Simulation wird ein Unterverzeichnis angelegt, z. B.:

```
simulationen/wellenueberlagerung/
  index.html
  simulation.js
  README.md
```

Die Python-Version bleibt im jeweiligen bestehenden Repository. Dokumentierte Testfälle gewährleisten, dass beide Versionen physikalisch übereinstimmen.

Die erste geplante Referenzsimulation ist die Wellenüberlagerung.
